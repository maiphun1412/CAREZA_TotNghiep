# CAREZA RAG Retrieval Final Evaluation Dataset (v1)

## 1. Giới thiệu
Bộ dữ liệu Final Evaluation độc lập phục vụ đánh giá năng lực tổng quát hóa cuối cùng của 3 thuật toán Retrieval:
- Baseline TF-IDF
- Hybrid V1 (Ngưỡng cố định)
- Hybrid V2 (Dynamic Confidence Gate & Controlled Lexical Fallback)

## 2. Quy mô
- **Số tài liệu**: 14 documents mới
- **Số chunks**: 27 chunks (chia bằng TextChunker chuẩn)
- **Số câu hỏi**: 52 queries (46 câu có đáp án, 6 câu unanswerable với từ khóa bẫy)

## 3. Tuyên bố từ chối trách nhiệm (Disclaimer)
Dữ liệu tổng hợp phục vụ mục đích Final Evaluation cho RAG Retrieval, nhãn tham chiếu chưa được chuyên gia độc lập bên ngoài xác nhận.
